# Completed test output and shared trace retirement

1. Admit completed test executables and objects through recorded, successful
   compiler output arguments and terminal owner reports. Keep existing commands,
   results and diagnostics; do not create source/configuration archives for
   disposable products. File names alone never establish ownership.
2. Admit complete hardlink groups only when every name has its own qualified
   owner evidence. Raw traces retain full audit, input, build and source checks.
   Unknown aliases, current contracts, holds and active consumers protect the
   entire physical file.
3. Batch qualified file removals under one durable journal. Recheck controls,
   pins, consumers, evidence and file identities before unlinking; restore all
   names on a pre-unlink failure. Count each physical allocation exactly once.
4. Qualify Debug and ReleaseFast, exercise rollback and alias guards, install
   the collector, review real candidates and collect only verified products.
5. Record exact reclamation, remaining blockers and a fresh inventory. New jobs
   use tools/run-validation with an explicit storage owner and managed output.

Starting inventory: 133.554 GiB in main local-state, including 28.75 GiB of
unresolved executables and 4.88 GiB of unresolved objects/archives. These category
totals are investigation scope, not permission to delete every member. Two
known shared raw-trace groups account for 2,894,225,408 allocated bytes.

## Implementation

`prepare-outputs --reports FILE` binds products to passed owner reports and
explicit successful compiler output arguments, including extensionless test
names and hash-bound direct compiler copies. Shell-wrapped and implicit outputs
stay unresolved. Compiled-file magic, ownership, current consumers and pins
remain mandatory. Each action retains its own diagnostics; command indexes are
shared within one collector invocation, with unchanged evidence checks.

`--complete-artifact-aliases` admits a physical group only when every name has
qualified evidence. The original four trace names now have independent verified
audits. The v34 alias uses its original terminal whole-build report, successful
build prefix and exact embedded capture; no producer receipt was fabricated.

File mutations share the existing policy budget, at most 1024 names per batch.
The collector quarantines every member, refreshes controls/pins/consumers, checks
evidence and hashes, and counts physical allocation on the last unlink. Invalid
alias accounting is rejected before quarantine. Pre-unlink failures restore all
names; interruption or partial removal leaves a durable journal.
